## 1. 개요 (Overview)

### 1.1 이 제품은 무엇인가?
CashCompass는 개인이 수입, 지출, 예산을 한 곳에서 관리할 수 있는 웹 애플리케이션입니다.
사용자는 자신의 돈이 어디에 쓰이는지 확인하고 미래를 계획할 수 있으며, **발생주의 회계 기준(Accrual Basis)** 으로 현금 흐름을 분석할 수 있습니다.

무엇보다도, **사용자는 발생주의 뷰와 현금 뷰를 나란히 비교하며 재무 현황을 종합적으로 파악할 수 있습니다.** 이 이중 뷰 관점이 다른 가계부 앱과 CashCompass를 구분하는 핵심 차별점입니다.

> **발생주의(Accrual Basis)란?**
> 돈이 실제로 들어오거나 나갈 때가 아니라, 비용이나 수익이 **발생한 시점**을 기준으로 기록하는 방식입니다.
> 예: 연간 구독료 12만원을 1월에 결제했더라도, 발생주의로는 매월 1만원씩 12개월에 걸쳐 비용으로 인식합니다.

### 1.2 우리가 해결하려는 문제
많은 사람들이 은행 앱, 엑셀, 영수증 등 여러 곳에 분산된 방식으로 재무를 관리하다 보니 지출을 놓치는 경우가 많습니다.
이런 도구들은 단순한 내역만 보여줄 뿐, 미래의 현금 흐름을 예측하는 기능이 없습니다.

예를 들어, 신용카드로 연간 멤버십을 결제한 경우, 실제 현금은 지금 나가지 않습니다.
카드 결제일에 한꺼번에 빠져나가지만, 재무 분석 관점에서는 해당 비용을 월별로 나눠서 봐야 합니다.
CashCompass는 이런 상황을 자동으로 처리해, 발생주의 뷰에서는 월별로 분할된 금액을, 현금 뷰에서는 실제 결제일 기준 금액을 보여줍니다.

### 1.3 누구를 위한 앱인가? (타겟 사용자)
- 복잡한 현금 흐름을 관리하고 싶은 개인
- 전문 회계 소프트웨어는 부담스럽지만 체계적인 관리를 원하는 사람
- 수입과 지출을 한눈에 볼 수 있는 대시보드를 원하는 누구나

> 타겟 사용자는 회계 지식이 없는 일반인입니다. 앱 UI에서는 "발생 인식일" 같은 회계 용어 대신 "이 지출은 몇 월에 해당하나요?"처럼 일상적인 표현을 사용합니다.

## 3. 주요 기능 (Key Features)

### 기능 1: 거래 내역 입력 (Transaction Entry)
- 사용자는 금액, 카테고리, 날짜, 메모, 결제 수단을 입력해 거래를 추가할 수 있습니다
- 거래마다 두 가지 날짜를 입력합니다:
  - **귀속 월 (Recognition Month)** — 이 지출이 어느 달에 해당하는지 (발생주의 뷰 기준)
  - **결제일 (Payment Date)** — 실제로 현금이 빠져나가는 날짜 (현금 뷰 기준)
- 일시불 지출 분할 (예: 연간 멤버십 12만원):
  - 사용자가 총 금액, 분할 개월 수, 시작 월을 직접 선택
  - 시스템이 해당 개월에 걸쳐 금액을 균등하게 나눠 발생주의 뷰에 반영
- 수입도 동일한 방식으로 월별 분할 가능 (예: 연말 보너스를 12개월에 걸쳐 분할)
- 분할 거래의 금액을 수정할 경우, 앱이 물어봅니다: "모든 달에 적용할까요, 아니면 이후 달에만 적용할까요?" — 매번 사용자가 선택
- 거래마다 영수증 사진 1장 첨부 가능 (JPG/PNG/HEIC, 최대 5 MB; 서버에 저장, 저장 시 암호화)
- 거래 수정 및 삭제 가능
- 거래 내역을 날짜 범위, 카테고리, 금액, 결제 수단으로 필터링 및 검색 가능
- **카테고리:**
  - 기본 카테고리: 식비, 교통, 주거, 공과금, 여가/문화, 의료/건강, 급여, 기타
  - 사용자가 직접 카테고리를 추가/이름 변경/삭제할 수 있음

### 기능 2: 결제 수단 관리 (Payment Method Management)
- 신용카드와 은행 계좌를 결제 수단으로 등록할 수 있습니다
- 신용카드 등록 시 다음 정보를 입력합니다:
  - 카드 이름 (예: "카카오뱅크 비자")
  - 사용기간 시작일 (예: 매월 1일)
  - 사용기간 마감일 (예: 매월 말일)
  - 결제일 (예: 다음 달 25일)
- 시스템이 거래 날짜와 사용기간을 비교해 해당 거래가 어느 결제 주기에 속하는지 자동 분류한 후, 실제 현금 유출일을 자동 계산합니다
- 대시보드에서 어떤 결제 수단에서 언제 현금이 나가는지 확인할 수 있습니다

> **예시:** 사용기간 1일~말일 / 결제일 다음 달 25일로 등록한 경우,
> 1월 20일에 발생한 거래는 1월 사용기간에 속하므로 현금 유출일은 2월 25일로 자동 계산됨

### 기능 3: 대시보드 — 이중 뷰 (Dashboard — Dual View)
- 기본 화면은 현재 월의 **발생주의 뷰**와 **현금 뷰**를 나란히 표시합니다
- **발생주의 뷰 (Accrual View)**: 비용이 귀속된 달 기준으로 지출을 표시 (실제 결제일과 다를 수 있음)
- **현금 뷰 (Cash View)**: 실제로 현금이 나가는 달 기준으로 지출을 표시
- 각 뷰에서 총 수입, 총 지출, 순 잔액을 확인할 수 있습니다
- 과거 및 미래 월로 자유롭게 이동 가능

### 기능 4: 현금 흐름 예측 (Cash Flow Projection)
- 사용자가 미래 예정 거래를 직접 입력할 수 있습니다 (예: 다음 달 월세, 예정된 여행 비용)
- 거래 날짜가 오늘 이후면 **"예정"**, 날짜가 지나면 **"실적"**으로 자동 구분 — 별도 플래그 없이 날짜만으로 판단
- 예정 거래의 날짜가 지났는데 수정되지 않은 경우, 다음 대시보드 진입 시 시스템이 묻습니다: *"이 거래가 실제로 발생했나요?"* — 사용자는 확정(실적 전환), 수정, 삭제 중 선택
- 대시보드에서 향후 12개월의 월별 예상 잔액을 확인할 수 있습니다
- 월별 현금 흐름 꺾은선 그래프로 시각화됩니다
- **가상 시나리오 모드 (What-if, v1.1)**: 특정 카테고리를 조정하면 (예: 식비 30% 감소) 예측이 어떻게 바뀌는지 확인 가능
- 가상 시나리오는 임시 데이터 — 실제 거래로 저장되지 않습니다

### 기능 5: 예산 관리 (Budget Management)
- 카테고리별 월 지출 한도를 설정할 수 있습니다
- 각 카테고리별 사용률을 프로그레스 바로 시각화합니다
- 예산의 80% 도달 시 노란색 경고 표시
- 예산 초과 시 빨간색 경고 표시
- 예산 설정은 다음 달에도 그대로 유지됩니다 (변경 전까지)

### 기능 6: 차트 및 분석 (Charts and Analysis)
- 카테고리별 지출: 선택한 월의 파이 차트
- 월별 트렌드: 최근 6개월 수입 vs. 지출 막대 그래프
- 현금 흐름 예측: 향후 12개월 꺾은선 그래프 (기능 4와 연동)
- 모든 차트는 발생주의 뷰와 현금 뷰 모두에서 작동합니다

### 기능 7: 데이터 내보내기 (Data Export)
- 거래 내역을 CSV 파일로 내보낼 수 있습니다 (엑셀 등 스프레드시트 활용)
- 월별 요약 리포트를 PDF로 내보낼 수 있습니다 (인쇄 가능한 형식)
- 내보내기 전 월과 카테고리로 필터링 가능

### 기능 8: 사용자 계정 (User Account)
- 이메일과 비밀번호로 회원가입 및 로그인
- 회원가입 시 기본 통화 설정 (예: KRW, USD, EUR) — 모든 거래에 이 통화가 적용됩니다
- 각 사용자의 데이터는 완전히 비공개 — 다른 사용자가 볼 수 없습니다
- 이메일로 비밀번호 재설정 가능
- 계정 설정에서 이메일, 비밀번호, 기본 통화 변경 가능
- **통화 변경 동작:** 기본 통화를 변경해도 과거 거래는 원래 통화 그대로 유지됩니다 (소급 변환 없음). 여러 통화의 거래가 공존할 경우, 대시보드와 리포트는 통화별 합계를 별도로 표시합니다 (예: "KRW 합계: ₩1,000,000 | USD 합계: $500")

### 기능 9: AI 스마트 가져오기 — 캡처 사진 업로드 (AI Smart Import)
- 사용자가 은행 또는 카드사 앱의 스크린샷을 업로드할 수 있습니다
- AI가 이미지를 분석해 여러 거래 항목을 자동으로 추출합니다:
  - 거래 날짜
  - 가맹점명 또는 내용
  - 금액
  - 추천 카테고리 (AI 추정값 — 사용자가 변경 가능)
- 저장 전 반드시 **검토 화면**이 표시됩니다 — 추출된 모든 항목을 리스트로 보여줌
- 검토 화면에서 사용자는:
  - 각 항목의 모든 필드(날짜, 금액, 카테고리, 귀속 월, 결제 수단)를 수정할 수 있습니다
  - 원하지 않는 항목을 삭제할 수 있습니다
  - 항목별로 선택/해제할 수 있습니다
- 선택된 항목을 한 번에 일괄 저장합니다
- v1 지원 이미지 유형: 은행 및 카드사 앱 스크린샷
- AI가 명확히 읽지 못한 항목은 "수동 확인 필요" 표시와 함께 별도로 표시됩니다

> **개인정보 보호:** 스크린샷에는 민감한 금융 정보가 포함되므로, 이미지는 추출 즉시 폐기됩니다 — 서버에 영구 저장하지 않습니다.

## 4. 사용자 흐름 (User Flow)

```
회원가입 / 로그인
      ↓
대시보드 (발생주의 뷰 + 현금 뷰 나란히, 현재 월)
      ↓
거래 추가
  → 금액, 카테고리, 귀속 월, 결제일, 결제 수단, 메모 입력
  → 일시불 분할의 경우: 총 금액 + 개월 수 + 시작 월 선택 → 시스템이 자동 분할
  → 저장
      ↓
결제 수단 등록
  → 신용카드 추가 → 카드 결제일 입력
  → 시스템이 기존 거래의 현금 유출일을 자동 업데이트
      ↓
예산 설정
  → 카테고리 선택 → 월 한도 금액 입력
  → 80% 도달 시 경고 확인
      ↓
현금 흐름 예측 보기
  → 미래 예정 거래 입력
  → 가상 시나리오 토글 → 카테고리 조정 → 업데이트된 예측 확인
      ↓
차트 분석
  → 발생주의 뷰 / 현금 뷰 전환
  → 트렌드 분석을 위한 월 범위 선택
```

## 5. 비기능 요구사항 (Non-Functional Requirements)

> **비기능 요구사항이란?**
> "무엇을 하는가"가 아닌 "어떻게 동작해야 하는가"에 대한 기준입니다.
> 속도, 보안, 지원 환경 등이 여기에 해당합니다.

| 항목 | 요구사항 |
|------|----------|
| 성능 | 모든 페이지는 2초 이내에 로딩되어야 함 |
| 보안 | 비밀번호는 암호화 저장, 사용자 데이터는 계정별로 완전히 분리 |
| 지원 플랫폼 | 데스크톱 브라우저 (Chrome, Firefox, Safari, Edge) |
| 모바일 | 스마트폰 브라우저에서 사용 가능한 반응형 디자인 (이중 뷰는 탭 토글 방식) |

## 6. 성공 기준 (Success Metrics)

> **성공 기준이란?**
> 기능이 제대로 동작하는지 확인할 수 있는 구체적이고 측정 가능한 조건입니다.

- 사용자가 분할 설정 포함 거래를 60초 이내에 입력할 수 있다
- 분할 지출에 대해 발생주의 뷰와 현금 뷰가 서로 다른 올바른 값을 표시한다
- 카테고리 예산의 80%에 도달했을 때 경고가 정확히 표시된다
- 미래 예정 거래를 추가하면 예측 차트가 즉시 업데이트된다
- 가상 시나리오 모드가 실제 저장된 거래 데이터를 변경하지 않는다
