#### 검증 기준

- [ ] 신용카드 등록 (사용기간 1일~말일, 결제일 다음 달 25일) 성공
- [ ] 신용카드 등록 (사용기간 16일~15일, 결제일 다음 달 10일) 성공
- [ ] 은행 계좌 등록 성공
- [ ] 거래 입력 시 카드 선택 → 결제일 자동 계산 표시
  - 1월 20일 거래 + 카드(1일~말일, 다음 달 25일) → 결제일: 2월 25일 ✓
  - 1월 20일 거래 + 카드(16일~15일, 다음 달 10일) → 결제일: 3월 10일 ✓
- [ ] 거래 입력 시 은행 계좌 선택 → 결제일 = 거래일 ✓
- [ ] 카드 결제 주기 수정 → 기존 거래 결제일 자동 업데이트 + 건수 표시
- [ ] 카드 삭제 → 기존 거래의 결제 수단이 NULL로 변경 (거래는 유지)

**결제일 계산 테스트 케이스:**

```
테스트 1: 사용기간 1일~말일, 결제일 다음 달 25일
  2026-01-05 → 2026-02-25 ✓
  2026-01-31 → 2026-02-25 ✓
  2026-02-28 → 2026-03-25 ✓  (2월 말일)
  2026-12-25 → 2027-01-25 ✓  (연도 넘김)

테스트 2: 사용기간 16일~15일, 결제일 다음 달 10일
  2026-01-20 → 2026-03-10 ✓  (1/16~2/15 기간 → 마감 2월 → +1 = 3월)
  2026-01-10 → 2026-02-10 ✓  (12/16~1/15 기간 → 마감 1월 → +1 = 2월)
  2026-02-15 → 2026-03-10 ✓  (1/16~2/15 기간의 마지막 날)
  2026-02-16 → 2026-04-10 ✓  (2/16~3/15 기간 → 마감 3월 → +1 = 4월)

테스트 3: 사용기간 1일~말일, 결제일 같은 달 27일
  2026-01-05 → 2026-01-27 ✓  (payment_month_offset = 0)
```
