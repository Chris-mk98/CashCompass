## 1. 글로벌 네비게이션

> 로그인 후 모든 페이지 상단에 공통으로 표시되는 네비게이션 바입니다.
> 관련 유저 스토리: US-021

### 1-1. 데스크톱 네비게이션 바

```
+------------------------------------------------------------------------+
| CASHCOMPASS   대시보드  거래내역  예산  차트  내보내기        [👤 설정 ▾] |
+------------------------------------------------------------------------+
```

- 로고 클릭 → 대시보드로 이동
- 현재 페이지의 메뉴 항목은 하이라이트 처리
- [👤 설정 ▾] 클릭 시 드롭다운 표시:

```
                                            +-----------------+
                                            | 결제 수단 관리   |
                                            | 카테고리 관리    |
                                            | 계정 설정       |
                                            |-----------------|
                                            | 로그아웃        |
                                            +-----------------+
```

### 1-2. 모바일 네비게이션

```
+--------------------------------------------+
| ☰  CASHCOMPASS                    [👤]     |
+--------------------------------------------+

+--------------------------------------------+
| 대시보드 | 거래내역 | 예산 | 차트 | 더보기  |
+--------------------------------------------+
```

- 상단: 햄버거 메뉴(☰)와 프로필 아이콘
- 하단: 탭 바 (5개 주요 메뉴)
- "더보기" 탭: 내보내기, 결제 수단, 카테고리, 계정 설정, 로그아웃

## 3. 대시보드 — 이중 뷰

> 관련 유저 스토리: US-009, US-010, US-011, US-015
> PC에서는 발생주의/현금 뷰를 나란히, 모바일에서는 탭 토글로 전환

### 3-1. 데스크톱 대시보드

```
+------------------------------------------------------------------------+
| CASHCOMPASS   대시보드  거래내역  예산  차트  내보내기        [👤 설정 ▾] |
+------------------------------------------------------------------------+
|                                                                        |
|                  [< ] 2026년 5월 [📅] [ >]                             |
|                                                                        |
|  +--- 예정 거래 알림 (US-011) -----------------------------------+     |
|  | ⚠ 확인이 필요한 예정 거래가 2건 있습니다.        [ 확인하기 ]   |     |
|  +---------------------------------------------------------------+     |
|                                                                        |
|  +--- 발생주의 뷰 -------------------+ +--- 현금 뷰 -----------------+ |
|  |                                   | |                             | |
|  |  총 수입     ₩3,500,000           | |  총 수입     ₩3,500,000     | |
|  |  총 지출     ₩2,180,000           | |  총 지출     ₩2,850,000     | |
|  |  ─────────────────────            | |  ─────────────────────      | |
|  |  순 잔액     ₩1,320,000           | |  순 잔액       ₩650,000     | |
|  |                                   | |                             | |
|  |  카테고리별 지출 ──────            | |  카테고리별 지출 ──────      | |
|  |  식비       ₩450,000  ████░ 75%   | |  식비       ₩450,000        | |
|  |  교통       ₩180,000  ██░░░ 40%   | |  교통       ₩180,000        | |
|  |  주거       ₩800,000  ████░ 80%   | |  주거     ₩1,500,000        | |
|  |  공과금     ₩150,000  ██░░░ 38%   | |  공과금     ₩150,000        | |
|  |  여가       ₩200,000  ███░░ 60%   | |  여가       ₩200,000        | |
|  |  ///                              | |  ///                        | |
|  |                                   | |                             | |
|  +-----------------------------------+ +-----------------------------+ |
|                                                                        |
|  +--- 예산 경고 (US-015) ----------------------------------------+     |
|  | 🟡 주거 예산 80% 도달 (₩800,000 / ₩1,000,000)                |     |
|  | 🔴 식비 예산 초과! (₩450,000 / ₩400,000)                      |     |
|  +---------------------------------------------------------------+     |
|                                                                        |
|  [ + 새 거래 추가 ]    [ 📷 스마트 가져오기 ]                           |
|                                                                        |
+------------------------------------------------------------------------+
```

**동작:**
- [< ] [ >] : 이전/다음 달 이동
- [📅] : 월 선택기 팝업 → 특정 월로 바로 이동
- 예정 거래 알림: 날짜가 지난 예정 거래가 있을 때만 표시
- 카테고리별 지출의 프로그레스 바: 예산 대비 사용률 (예산이 설정된 카테고리만)
- 프로그레스 바 색상: 0~79% 파란색, 80~99% 노란색, 100%+ 빨간색
- 발생주의/현금 뷰의 금액이 분할 거래에 대해 다르게 표시됨

### 3-2. 예정 거래 확인 다이얼로그

> 날짜가 지난 예정 거래에 대해 사용자에게 확인을 요청합니다.
> 관련 유저 스토리: US-011

```
+----------------------------------------------+
|         예정 거래 확인                         |
|----------------------------------------------|
|                                              |
|  다음 거래의 날짜가 지났습니다.               |
|  실제로 발생했나요?                           |
|                                              |
|  2026-05-15  식비  ₩35,000                   |
|  메모: 팀 점심 식사                           |
|                                              |
|  [  확정 (실적 전환)  ]                       |
|  [  수정 (날짜/금액 변경)  ]                  |
|  [  삭제  ]                                  |
|                                              |
|        1 / 2              [ 다음 > ]          |
+----------------------------------------------+
```

## 4. 거래 입력

> 관련 유저 스토리: US-001, US-002, US-003, US-004, US-026

### 4-1. 기본 거래 추가 폼

```
+----------------------------------------------+
|  새 거래 추가                          [ ✕ ] |
|----------------------------------------------|
|                                              |
|  거래 유형                                    |
|  (o) 지출    ( ) 수입                         |
|                                              |
|  금액                                        |
|  [v ₩ ] [________________]                   |
|                                              |
|  카테고리                                     |
|  [v 카테고리 선택          ▾]                 |
|                                              |
|  이 지출은 어느 달에 해당하나요? (귀속 월)      |
|  [v 2026년 5월             ▾]                |
|                                              |
|  결제 수단                                    |
|  [v 카카오뱅크 비자         ▾]                |
|                                              |
|  결제일 (자동 계산됨)                          |
|  2026년 6월 25일  ℹ                          |
|                                              |
|  메모 (선택사항)                              |
|  [____________________________]              |
|                                              |
|  영수증 사진 (선택사항)                        |
|  [ 📎 파일 선택 ]  JPG, PNG, HEIC / 최대 5MB  |
|                                              |
|  [ ] 여러 달에 나눠서 기록하기                 |
|                                              |
|  [        저장        ]    [ 취소 ]           |
+----------------------------------------------+
```

**동작:**
- 결제 수단이 신용카드 → 결제일 자동 계산 (카드의 사용기간/결제일 기반)
- 결제 수단이 은행 계좌 → 결제일 = 거래일 (귀속 월의 날짜)
- ℹ 아이콘 호버 시: "카카오뱅크 비자 — 사용기간 1일~말일, 결제일 다음 달 25일" 표시
- "여러 달에 나눠서 기록하기" 체크 → 분할 입력 섹션 확장 (4-2 참조)

### 4-2. 분할 입력 섹션 (확장 시)

> "여러 달에 나눠서 기록하기" 체크박스 선택 시 아래 섹션이 나타납니다.

```
|  ┌─ 분할 설정 ──────────────────────────┐    |
|  │                                      │    |
|  │  총 금액                              │    |
|  │  ₩120,000                            │    |
|  │                                      │    |
|  │  몇 개월로 나눌까요?                   │    |
|  │  [v 12개월               ▾]          │    |
|  │                                      │    |
|  │  시작 월                              │    |
|  │  [v 2026년 1월            ▾]          │    |
|  │                                      │    |
|  │  ── 분할 미리보기 ─────────────       │    |
|  │  2026년 1월   ₩10,000                │    |
|  │  2026년 2월   ₩10,000                │    |
|  │  2026년 3월   ₩10,000                │    |
|  │  ///                                 │    |
|  │  2026년 12월  ₩10,000                │    |
|  │  ──────────────────────              │    |
|  │  합계: ₩120,000 (12개월)              │    |
|  │                                      │    |
|  └──────────────────────────────────────┘    |
```
